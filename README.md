# GlowLights

A lightweight **server-side dynamic lights plugin** for Minecraft 1.21+.

GlowLights lets players have dynamic light sources while moving around without needing a client-side mod. It supports **Paper and Folia** and is made to keep the performance impact as low as possible.

### Features

- Server-side dynamic lights
- Minecraft **1.21+**
- **Paper & Folia** support
- Per-player toggle
- Disable GlowLights in specific worlds
- Lightweight and optimized
- No client-side mod required
- Configurable light sources
- Smooth lighting
Simple dynamic lighting for your server without adding unnecessary overhead.
